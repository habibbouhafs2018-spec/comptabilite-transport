# نظام محاسبة النقل - الجزائر

نظام محاسبي احترافي لإدارة مؤسسة نقل البضائع.

## المواصفات
- اللغة العربية واتجاه RTL.
- العملة: الدينار الجزائري DZD.
- النظام المحاسبي: SCF الجزائري.
- المحاسبة بالقيد المزدوج.
- شجرة حسابات رسمية مع حسابات فرعية لنشاط النقل.
- إدارة العملاء والموردين.
- إدارة الشاحنات والمقطورات والسائقين.
- تسجيل الرحلات وأسعارها وكمياتها.
- إدارة عهد السائقين وتسويتها.
- إدارة المصاريف والأجور.
- دفتر اليومية ودفتر الأستاذ العام.
- ميزان المراجعة والتقارير المالية.

## التقنية
- قاعدة بيانات PostgreSQL / Supabase.
- واجهة ويب متوافقة مع الهواتف.
